Stopwatch Web Application

A responsive and user-friendly stopwatch built using HTML, CSS, and JavaScript. This web application enables users to measure and record time intervals with precision, including lap tracking. It features intuitive controls for starting, pausing, resetting, and recording laps.

Features

Start, pause, and reset controls

Lap time recording

Accurate time tracking

Clean and responsive user interface


Technologies Used

HTML – for structuring the application

CSS – for styling and layout

JavaScript – for stopwatch functionality and logic

How to Use

1. Clone or download the repository
2. Open index.html in your web browser
3. Use the on-screen buttons to control the stopwatch
